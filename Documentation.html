Loopkind · WordPress Theme

Theme documentation

A practical guide to installing and configuring the Loopkind refill and reuse storefront theme.

1. Requirements

  • WordPress 6.6 or later.
  • PHP 7.4 or later. A currently supported PHP release is recommended by your hosting provider.
  • WooCommerce is optional. Install a current supported release if you need product, cart, checkout and account functionality.

The theme does not bundle WooCommerce or other third-party plugins. Store functions, payment methods, tax, shipping and legal notices are configured through WooCommerce and your own service providers.

2. Install the theme

  1. Sign in to your WordPress dashboard.
  2. Open Appearance → Themes → Add New → Upload Theme.
  3. Select the installable loopkind.zip file, choose Install Now, then activate Loopkind.
  4. Open Appearance → Themes and confirm Loopkind is active.

If WordPress reports that the theme is missing a stylesheet, you selected the outer Main Files archive instead of the installable WordPress theme ZIP.

3. Build the home page

  1. For an online store, install and activate WooCommerce first. Its Product Collection block powers the live product grid in the home pattern.
  2. Create a new page called Home and open it in the WordPress block editor.
  3. Open the block inserter, choose Patterns → Loopkind, and insert Loopkind — Refill shop home.
  4. Edit the text, links and category cards to match your shop, then assign the page under Settings → Reading.

The product section automatically queries published, in-stock products from WooCommerce. If no products appear, confirm WooCommerce is active and at least one product is published and in stock. The category cards above the grid are editable editorial content; link them to your real product categories.

Other patterns include a brand story, refill steps, FAQs and a refill product information guide. Patterns use WordPress core blocks and remain editable in the block editor.

Important: Pattern copy is starter content. Confirm every product detail, size, container option, return condition, address, delivery region and environmental statement before publishing.

4. Site identity, navigation and styling

  • Set the site title and tagline in Settings → General.
  • Upload a logo in Appearance → Customize → Site Identity or the equivalent Site Identity controls provided by your WordPress installation.
  • Create and assign a primary menu under Appearance → Menus. Assign a separate footer menu if needed; the footer navigation area stays hidden until one is assigned.
  • Set your site icon using WordPress Site Identity settings.
  • Use the Site Editor's global Styles controls to adjust the theme palette, custom colors and font sizes.

The mobile navigation remains visible if JavaScript is disabled; with JavaScript enabled it can be opened by keyboard or touch and closed with Escape. The theme uses system fonts and local assets and does not request web fonts or analytics from third-party servers.

5. WooCommerce

  1. Install and activate the official WooCommerce plugin.
  2. Complete WooCommerce setup and confirm its Shop, Cart, Checkout and My Account pages.
  3. Add your products, product images, prices, stock details, shipping and tax settings.
  4. Open the Shop page and check product archives, a single product, the cart, checkout and My Account on desktop and mobile.

Loopkind provides theme support, presentation styling, a cart link with a live item count refreshed from the WooCommerce Store API, an optional My Account link, and a dynamic product collection pattern. It does not replace WooCommerce templates or remove their hooks. Payment and checkout availability depend on your WooCommerce configuration and extensions.

For refill products, insert Refill product — useful details into the product description and edit the container and return guidance to match the actual item. This pattern is informational only; it does not calculate deposits, manage packaging returns or change checkout behavior.

6. Blog, comments and widgets

The standard index.php template displays the latest posts. Category, tag, date archive, search and single-post templates are included. Add widgets to Appearance → Widgets to show the optional Blog Sidebar. The sidebar is hidden from visitors when it contains no widgets.

Comments follow WordPress discussion settings. You can enable, moderate or close comments in the dashboard.

7. Accessibility and languages

The theme includes a skip link, visible keyboard focus, semantic landmarks, reduced-motion support and responsive navigation. Content and labels use the loopkind text domain and can be translated. A loopkind.pot translation template is included in the languages folder.

8. Included assets and credits

Theme illustrations are original SVG files included in the theme package. The front end uses system fonts and local assets. No commercial stock photo, paid font, external JavaScript library or remote image service is bundled.

Product imagery visible in preview screenshots is illustrative and is not included as a WooCommerce product catalog. Add your own licensed product images before publishing.

9. Troubleshooting

  • Layout looks unchanged: clear your browser, page-cache and CDN caches, then reload the site.
  • Home page still shows posts: assign the Home page under Settings → Reading.
  • Menu is missing: create a menu and assign it to the Primary Menu location.
  • Home product grid is empty: activate WooCommerce and check that products are published and in stock.
  • Shop pages are missing: install WooCommerce and complete its setup. The theme alone does not create store pages or products.
  • Image does not load: verify the image is attached to the page or product and that the media URL is available over HTTPS.
